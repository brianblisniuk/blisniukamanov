# Pasaporte Negro — Kit de logo

## Archivos
- **sello-principal** (marfil / negro): marca principal. Uso >= 80 px.
- **simbolo** (marfil / negro): de 24 a 79 px, o como avatar.
- **wordmark**: versión tipográfica con tagline TURISMO DE LUJO.
- **lockup-horizontal**: símbolo + nombre, para headers y firmas.
- **sello-admitido**: elemento gráfico secundario (nunca sustituye al logo).
- **favicon.svg**: globo simplificado para 16–32 px.
- **tokens.css**: paleta y fuentes como variables CSS.

## Tipografías (Google Fonts — instalar antes de abrir los SVG)
- Marcellus (display / marca): https://fonts.google.com/specimen/Marcellus
- Cormorant Garamond (editorial): https://fonts.google.com/specimen/Cormorant+Garamond
- Jost (funcional): https://fonts.google.com/specimen/Jost
Los SVG usan texto vivo; para producción final convertir texto a curvas en Illustrator/Figma.

## Paleta (monocromo — dorado prohibido)
- Negro Abismo #0A0A0B · fondo principal
- Negro Carbón #101012 · superficies
- Marfil #E8E6E0 · marca y texto
- Humo #8A8F97 · secundario
- Grafito #3A3B3F · líneas

## Reglas rápidas
- Área de respeto: X/4 del diámetro del sello por cada lado.
- Versión marfil sobre negros; versión negra sobre marfil o fondos claros.
- Sin dorado, sin color saturado. El brillo lo dan los acabados: foil plata mate, relieve seco, negro sobre negro.
